- mes projets d'école et perso : CommunityHub, Voyage, un assistant vocal sur Raspberry Pi, un site de recettes en PHP...
- mon parcours et les technos que j'utilise
- Penquest, mon projet de fin d'études en cours

## Technique

Site statique en HTML, CSS et JavaScript, sans framework ni build. J'ai voulu quelque chose de léger et rapide à charger.

- thème sombre par défaut avec un mode clair (le choix est gardé dans le localStorage)
- filtres sur les projets (web, mobile, back-end)
- responsive mobile / tablette / ordi
- polices Space Grotesk et JetBrains Mono (Google Fonts)

## Lancer en local

```
git clone https://github.com/bilelbts/bilelbts.github.io.git
cd bilelbts.github.io
```

Puis ouvrir `index.html` dans le navigateur.
